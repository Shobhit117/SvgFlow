## FlowStyle

```python
FlowStyle(*, node_shape: NodeShape=('circle', 20), node_color: Color='none', node_border: Color='black', node_thickness: Number=2, text_size: Number=16, text_color: Color='black', text_style: str | None=None, edge_color: Color='black', edge_thickness: Number=2, edge_text_size: Number | None=None, edge_text_color: Color | None=None, label_gap: Number=0.4, arrow_style: ArrowStyle | None=None, arrow_size: Number=1, stub: Number=20, corner_radius: Number=6, self_loop_size: Number=100)
```

Default appearance of nodes and edges in a `Flow`.

Every `Flow` drawing method falls back to these values for arguments
left as `None`, so a whole diagram can be restyled in one place::

    flow = Flow(400, 600, style=FlowStyle(node_color="aliceblue", edge_color="gray", arrow_style="stealth"))

* `node_shape`/`node_color`/`node_border`/`node_thickness`: node defaults.
* `text_size`/`text_color`/`text_style`: node label text.
* `edge_color`/`edge_thickness`: edge strokes.
* `edge_text_size`/`edge_text_color`: edge labels (`None` = same as node text).
* `label_gap`: gap between an edge and its label, in units of the label font size.
* `arrow_style`/`arrow_size`: arrowheads (`None` style = the canvas' `arrow_style`).
* `stub`/`corner_radius`: elbow-edge routing defaults.
* `self_loop_size`: default size of self-loops.

**Construction:**

Store defaults for future node/edge calls; existing SVG is unchanged.

Dimensions and stroke/font sizes use canvas units, `label_gap` uses
label-font multiples and `arrow_size` is a scale factor. See the
class docstring for field groups. Omitted edge label size/color follow
node text size/color. Individual drawing calls can override defaults.

## Flow

```python
Flow(height: Number, width: Number, *, style: FlowStyle | None=None, executables: ExecutablePaths | None=None)
```

A Canvas with manually positioned named nodes and routed edges.

All coordinates use canvas units and node positions denote centers.
Nodes must exist before edges refer to them. Layout and obstacle
avoidance are the caller's responsibility; calls append SVG immediately.

**Construction:**

Create an empty flow-diagram canvas whose defaults come from `style`.

## Flow.addNode

```python
Flow.addNode(id: str, x: Number, y: Number, shape: NodeShape | None=None, label: Any | None=None, color: Color | None=None, border: Color | None=None, thickness: Number | None=None, opacity: Number=1, text_color: Color | None=None, text_size: Number | None=None, text_style: str | None=None, latex: bool=False) -> None
```

Add a uniquely named node centered at canvas point `(x, y)`.

Supported shape tuples are `('circle', radius)`,
`('rectangle', height, width[, corner_radius])`,
`('ellipse', horizontal_radius, vertical_radius)`, and
`('parallelogram', diagonal1, diagonal2, angle_degrees)`.
The legacy spelling `'paralellogram'` is also accepted. Diagonals
and angle must describe a nondegenerate shape. Duplicate IDs raise
`KeyError`; unknown shapes raise `ValueError`.

Arguments left as `None` use `FlowStyle`. Labels accept
newlines/lists; they do not resize the node or wrap automatically.
`latex=True` renders math through external tools.

## Flow.addEdge

```python
Flow.addEdge(node1: str, node2: str, label: Any | None=None, curvature: Number=0, color: Color | None=None, thickness: Number | None=None, dashed: bool=False, directed: Directed=False, opacity: Number=1, text_color: Color | None=None, text_size: Number | None=None, text_style: str | None=None, latex: bool=False, *, arrow_size: Number | None=None, arrow_style: ArrowStyle | None=None) -> None
```

Connect distinct nodes with a straight or quadratic curved edge.

`curvature` offsets the control point from the center-to-center
chord midpoint. Endpoints lie on the node outlines in the directions
of that control point, then a new curve is drawn between them (not an
exact trim of the original center-to-center curve). Rounded rectangle
corners are honored. Positive curvature bends horizontal connections
upward and vertical connections right. Zero draws a straight edge.

`directed` defaults to False; arrow options match `Canvas.addLine`.
Missing or equal IDs raise `KeyError`; use `addSelfEdge` for
loops. Labels sit outside the curve apex. Unspecified style arguments
come from `FlowStyle`.

## Flow.addSelfEdge

```python
Flow.addSelfEdge(node: str, theta1: Number=60, theta2: Number=120, curvature: Number | None=None, label: Any | None=None, color: Color | None=None, thickness: Number | None=None, dashed: bool=False, directed: Directed=False, opacity: Number=1, text_color: Color | None=None, text_size: Number | None=None, text_style: str | None=None, arrow_size: Number | None=None, latex: bool=False, *, arrow_style: ArrowStyle | None=None) -> None
```

Add a self-loop leaving `node` at angle `theta1` and returning at `theta2`.

Angles are in degrees, clockwise from +x (so 90 is straight down). The
loop always bulges *outward*, leaving and re-entering perpendicular-ish
to the outline; `curvature` sets its size (the apex lies about
`curvature / 2` beyond the attachment points; the sign is ignored).
The label is placed just outside the loop's apex.

`curvature=None` uses `style.self_loop_size`. `directed`
defaults to False; pass True for a return arrow. A missing node raises
`KeyError`. Unspecified appearance comes from `FlowStyle`.

## Flow.addElbowEdge

```python
Flow.addElbowEdge(node1: str, node2: str, from_port: Port | None=None, to_port: Port | None=None, waypoints: Sequence[Point] | None=None, label: Any | None=None, label_segment: int | Literal['longest']='longest', stub: Number | None=None, corner_radius: Number | None=None, color: Color | None=None, thickness: Number | None=None, dashed: bool=False, directed: Directed=True, opacity: Number=1, text_color: Color | None=None, text_size: Number | None=None, text_style: str | None=None, arrow_size: Number | None=None, latex: bool=False, *, arrow_style: ArrowStyle | None=None) -> list[Point]
```

Connect two nodes with an orthogonal (elbow) edge.

`from_port`/`to_port` are the sides of `node1`/`node2` the edge
attaches to (`'N'`, `'S'`, `'E'`, `'W'`); when omitted they are
chosen so the nodes face each other. `stub` is the minimum distance
the edge travels straight out of a port before bending, and
`corner_radius` rounds the bends (0 gives sharp corners).

`waypoints` overrides automatic routing: the edge goes from the
port, through each waypoint in order, to the target port. Ports that
are not given are then chosen to face the first/last waypoint.

The label is placed on the longest segment by default, or on segment
`label_segment` (an index into the routed segments).

Returns the list of route points (useful for debugging/layout).

Waypoints are followed literally: no extra bends or stubs are
inserted in waypoint mode. Supply axis-aligned segments yourself.
Returned points precede corner rounding and arrow trimming; segment
indices refer to the simplified route. Automatic routing does not
avoid unrelated nodes. Unlike `addEdge`, directed defaults to
True. Missing/equal IDs raise `KeyError`; invalid ports raise
`ValueError`. Use `addSelfEdge` for loops.
