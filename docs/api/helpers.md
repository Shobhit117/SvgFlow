## ExecutablePaths


Immutable command names or paths for optional external programs.

Each field defaults to its command name, resolved using the subprocess
environment's PATH. Supply executable paths as strings or path-like objects;
do not add shell quotes or command-line flags to them. Only programs needed
by the requested operation are invoked. This object does not install or
validate executables. Pass it to Canvas, Plot, Figure, Flow or tex2svg.

<a id="register_font"></a>

## register_font

```python
register_font(name: str, regular: str, bold: str | None=None, italic: str | None=None, bold_italic: str | None=None, *, family: str | None=None, embed: bool=True) -> FontSpec
```

Register a font so it can be used via `addText(..., font=name)`.

`regular`/`bold`/`italic`/`bold_italic` are paths to TTF/OTF files
(or PyMuPDF built-in names). `family` is the CSS family written into the
SVG; it defaults to `name`. Re-registering a name replaces it.
Registration is process-wide and returns the resulting `FontSpec`.
Faces are loaded immediately; invalid files or built-in names propagate
the PyMuPDF loader's exception. Missing variants fall back towards regular.
Only file-backed faces can be embedded; `embed=False` relies on viewer
fonts for SVG display. Inkscape export exposes file faces separately.

| `name` | `required` | `str` |
| `regular` | `required` | `str` |
| `bold` | `None` | `str \| None` |
| `italic` | `None` | `str \| None` |
| `bold_italic` | `None` | `str \| None` |
| `family` | `None` | `str \| None (keyword-only)` |
| `embed` | `True` | `bool (keyword-only)` |

<a id="text_width"></a>

## text_width

```python
text_width(text: object, size: float, font: str=DEFAULT_FONT, bold: bool=False, italic: bool=False) -> float
```

Return the advance width of *text* at *size* in SVG user units.

`font` is a registered font name; for backwards compatibility a raw
PyMuPDF built-in name (e.g. `"helv"`) is also accepted.
`text` is converted to str; this helper measures one line, not a block.
`bold`/`italic` choose registered face variants. Negative sizes raise
`ValueError`. Invalid unregistered font names reach the font loader.
The result is glyph advance width, not a tight ink bounding box.

| --- | --- | --- |
| `text` | `required` | `object` |
| `size` | `required` | `float` |
| `font` | `'default'` | `str` |
| `bold` | `False` | `bool` |
| `italic` | `False` | `bool` |

<a id="wrap_text"></a>

## wrap_text

```python
wrap_text(text: object, size: float, max_width: float, font: str=DEFAULT_FONT, bold: bool=False, italic: bool=False) -> list[str]
```

Greedy word-wrap of *text* so each line fits within *max_width*.

Explicit newlines are preserved. A single word wider than `max_width` is
kept on its own line rather than being split.
Returns a list of strings, including empty lines for empty paragraphs.
Whitespace within paragraphs is normalized to single spaces; there is no
hyphenation. `size`/`max_width` use the same SVG user units as addText.
Font selection and invalid-size behavior follow `text_width`.

| `max_width` | `required` | `float` |
| `font` | `'default'` | `str` |
| `bold` | `False` | `bool` |

## import_svg_from_file

```python
import_svg_from_file(file_name: str | Path, fig_num: int | str) -> tuple[str, list[float]]
```

Return `(inner_markup, [min_x, min_y, width, height])` from a UTF-8 SVG.

The root must contain a whitespace-separated viewBox and an explicit svg
closing tag. Internal IDs/references are prefixed with `fig{fig_num}`.
Missing structure raises `RuntimeError`; file errors propagate. This
extracts markup without sanitizing it or bundling external resources.
Prefer Canvas.importSvgFromFile for direct placement on a canvas.

<a id="tex2svg"></a>

## tex2svg

```python
tex2svg(latex_math: str, eq_num: int, backend: Backend='inkscape', *, executables: ExecutablePaths | None=None) -> tuple[str, float, float]
```

Render a LaTeX math expression to SVG contents and return `(svg, width, height)`.

`latex_math` is math source without dollar delimiters; the standalone
template loads amsmath/amssymb and wraps it in display-style math. Requires
pdflatex plus the selected inkscape/dvisvgm/pdf2svg backend, found on PATH
or via `executables`. Identical expressions (for the same backend and
executable paths) are cached in memory for the current process.

The returned fragment excludes the outer svg element and has IDs prefixed
with `eq{eq_num}`; use unique equation numbers when composing fragments.
Width and height come from the converter's viewBox in SVG user units.
Missing programs raise `FileNotFoundError`; failed subprocesses or
unexpected SVG structure raise `RuntimeError`. An unsupported backend
raises `ValueError` after LaTeX compilation.

| Parameter | Default | Type / calling convention |
| --- | --- | --- |
| `latex_math` | `required` | `str` |
| `eq_num` | `required` | `int` |
| `backend` | `'inkscape'` | `Backend` |
| `executables` | `None` | `ExecutablePaths \| None (keyword-only)` |

[Source](../../svgflow/external_figures.py)

## FontSpec

```python
FontSpec(name: 'str', family: 'str', faces: 'dict[str, str]' = <factory>, embed: 'bool' = True) -> None
```

## uniquify_svg_ids

```python
uniquify_svg_ids(svg: str, prefix: str | None=None) -> str
```

Return markup with declared IDs and supported references prefixed.

Rewrites id attributes, url(#id), href and xlink:href references, leaving
undeclared targets unchanged. This is a regex-based helper, not a general
XML/CSS rewriter: CSS selectors and external resources are not resolved.
`prefix=None` produces the literal prefix `None_`; callers should pass
an explicit unique prefix when composing fragments.
