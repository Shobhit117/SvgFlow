## Canvas

```python
Canvas(height: Number, width: Number, *, background: Color | None=None, executables: ExecutablePaths | None=None)
```

Mutable SVG canvas.

Coordinates are expressed in SVG user units with the origin in the top-left
corner. Drawing methods append SVG snippets to the canvas; call `save`
to write the SVG file or `export` to rasterize/convert with Inkscape.

**Construction:**

Create a blank canvas, passing `height` before `width`.

Dimensions, positions, stroke widths and font sizes use SVG user units
(normally CSS pixels). The background is transparent by default; pass
`background` (e.g. `"white"`) for an opaque canvas fill.
`executables` configures optional LaTeX/export commands; ordinary SVG
needs no tools.

## Canvas.addText

```python
Canvas.addText(text: Any, x: Number, y: Number, color: Color='black', rotation: Number=0, baseline: TextBaseline='middle', anchor: TextAnchor='middle', size: Number=16, style: str | None=None, weight: str | Number | None=None, *, font: str | None=None, line_height: Number=1.2, max_width: Number | None=None, fit_width: bool=False, valign: Literal['top', 'center', 'bottom'] | None=None) -> tuple[float, float]
```

Add (possibly multi-line) text at `(x, y)`.

        `text` may contain `
` or be a list of lines. `max_width` enables
        automatic word wrapping. The block is aligned as a whole according to
        `baseline`: `"middle"` centres it on `y`, `"hanging"` grows
        downward from `y` and `"text-top"`/`"auto"` grow upward so the
        last line sits at `y` (`"text-top"` emits `dominant-baseline="auto"` for cross-browser consistency). Pass `valign` (top/center/bottom) to place
        the block independently of the per-line `baseline`. `font` is a
        registered font name (see
        `registerFont`); `fit_width` forces each rendered line to the
        measured width via `textLength`. Text is XML-escaped automatically.

        Returns the measured `(width, height)` of the text block.

        `anchor` selects the start, middle or end of each line at `x`;
        `rotation` is clockwise degrees about `(x, y)`. `line_height`
        is baseline spacing in multiples of `size`. Overlong words are not
        split. The returned height is `line_count * line_height * size`;
        width is the maximum line advance, not a tight glyph bounding box.

## Canvas.addLaTeX

```python
Canvas.addLaTeX(tex: str, x: Number, y: Number, scale: Number=1, rot: Number=0, baseline: PositionBaseline='middle', anchor: TextAnchor='middle', color: Color='black', backend: SvgBackend='inkscape') -> None
```

Render LaTeX math at `(x, y)` using external commands.

Pass math source without dollar delimiters, using raw Python strings
for backslashes. Requires pdflatex (standalone, amsmath, amssymb) and
the selected backend: inkscape, dvisvgm or pdf2svg. `scale` multiplies
the rendered dimensions; `rot` is clockwise degrees. `baseline`
selects top (hanging), center (middle) or bottom (text-top); `anchor`
selects left/start, center/middle or right/end before rotation.

Temporary conversion files are removed automatically. Missing commands
raise `FileNotFoundError`; failing conversions raise `RuntimeError`.
Compiled expressions are cached in memory for the current process.

| Parameter | Default | Type / calling convention |
| --- | --- | --- |
