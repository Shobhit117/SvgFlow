## Figure

```python
Figure(height: Number, width: Number, rows: int=1, cols: int=1, *, title: str | None=None, title_size: Number | None=None, style: PlotStyle | None=None, wspace: Number=10, hspace: Number=10, padding: Number=10, width_ratios: Sequence[Number] | None=None, height_ratios: Sequence[Number] | None=None, executables: ExecutablePaths | None=None)
```

A canvas holding a grid of `Plot` subplots.

The figure area (minus `padding` and an optional title band) is split
into `rows` x `cols` cells separated by `wspace`/`hspace`. Each
call to `subplot` returns an ordinary `Plot` sized to its
cell(s) and drawn in its own local coordinates; on save, every subplot is
translated into place and its SVG ids are prefixed so markers, gradients,
LaTeX glyphs, etc. never collide. The figure is itself a `Canvas`,
so you can draw annotations (e.g. arrows between subplots) in figure
coordinates; use `mapToFigure` to convert subplot data coordinates.

`style` is the default `PlotStyle` for all subplots. Subplots
use `origin="auto"`/`margins="auto"` by default so that subplots
sharing a style and compatible label-width estimates get aligned plot areas.

**Construction:**

Create a grid with user-unit padding, inter-cell gaps and a title band.

`rows`/`cols` must be positive. `width_ratios` and `height_ratios`
need one positive entry per column/row and divide space after gaps and
padding. Invalid ratios or insufficient grid space raise `ValueError`.
Create plots separately with `subplot` or `subplots`;
`style` supplies their defaults.

## Figure.subplot

```python
Figure.subplot(row: int, col: int, rowspan: int=1, colspan: int=1, *, x_range: Point=(0, 1), y_range: Point=(0, 1), origin: Point | Literal['auto'] | None='auto', margins: Point | Literal['auto'] | None='auto', style: PlotStyle | None=None, extra_margins: Sequence[Number]=(0, 0, 0, 0)) -> Plot
```

Create a `Plot` occupying the given grid cell(s) and return it.

`row`/`col` are zero-based. `origin`/`margins` are in the
subplot's local coordinates (see `Plot`).

Spans must remain inside the grid (`IndexError` otherwise).
Nonpositive spans or occupied cells raise `ValueError`. Font,
arrow-style and executable defaults are inherited at creation. Later
drawing on the returned Plot is reflected in subsequent figure saves.

| Parameter | Default | Type / calling convention |
| --- | --- | --- |
| `row` | `required` | `int` |
| `col` | `required` | `int` |
| `rowspan` | `1` | `int` |
| `colspan` | `1` | `int` |
| `x_range` | `(0, 1)` | `Point (keyword-only)` |
| `y_range` | `(0, 1)` | `Point (keyword-only)` |
| `origin` | `'auto'` | `Point \| Literal['auto'] \| None (keyword-only)` |
| `margins` | `'auto'` | `Point \| Literal['auto'] \| None (keyword-only)` |
| `style` | `None` | `PlotStyle \| None (keyword-only)` |
| `extra_margins` | `(0, 0, 0, 0)` | `Sequence[Number] (keyword-only)` |

## Figure.subplots

```python
Figure.subplots(*, x_range: Point=(0, 1), y_range: Point=(0, 1), style: PlotStyle | None=None) -> list[list[Plot]]
```

Fill an empty grid and return a nested list `axes[row][col]`.

All plots receive the same ranges and style. Use `subplot` for
mixed ranges or spans. An occupied grid can raise `ValueError` after
plots have been created in earlier unoccupied cells.

## Figure.mapToFigure

```python
Figure.mapToFigure(plot: Plot, x: Number, y: Number, data: bool=True) -> Point
```

Convert a point of `plot` to figure coordinates.

With `data=True` (default) `(x, y)` are data coordinates; otherwise
they are the subplot's local canvas coordinates.

A plot belonging to another figure raises `KeyError`.

| Parameter | Default | Type / calling convention |
| --- | --- | --- |
| `plot` | `required` | `Plot` |
| `x` | `required` | `Number` |
| `y` | `required` | `Number` |
| `data` | `True` | `bool` |
