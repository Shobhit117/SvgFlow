## PlotStyle

```python
PlotStyle(tick_size: Number=16, label_size: Number=16, title_size: Number=18, *, tick_length: Number=10, tick_pad: Number=0.35, label_pad: Number=0.5, title_pad: Number=0.6, outer_pad: Number=8, line_height: Number=1.2, axis_gap: Number=6, palette: PaletteName | Sequence[Color]='default')
```

Font sizes and font-relative spacing shared by a plot's text elements.

Every gap is expressed as a fraction of the font size of the text it
separates, so layouts stay balanced when font sizes change:

* `tick_pad`: gap between the outer end of a tick notch and its label,
  in units of `tick_size`.
* `label_pad`: gap between the outer edge of the tick labels and the
  axis label, in units of `label_size`.
* `title_pad`: gap between the top of the plot area and the title, in
  units of `title_size`.
* `outer_pad`: blank border (user units) kept around the content when
  margins are computed automatically (`origin="auto"` / `margins="auto"`).
* `tick_length`: total length of a tick notch (drawn centred on the axis).
* `axis_gap`: clearance (user units) between the edge of the plot area
  and the back of an axis arrowhead (or the end of an undirected axis), so
  the last tick and its grid line never touch the arrowhead.

**Construction:**

Set text sizes, notch length and outer padding in user units.

`tick_pad`, `label_pad` and `title_pad` are font-size multipliers;
`line_height` is used in text extent and automatic margin estimates.
See `PlotStyle` for the spacing conventions.

## Plot

```python
Plot(height: Number, width: Number, origin: Point | Literal['auto'] | None='auto', margins: Point | Literal['auto'] | None='auto', x_range: Point=(0, 1), y_range: Point=(0, 1), *, style: PlotStyle | None=None, extra_margins: Sequence[Number]=(0, 0, 0, 0), background: Color | None=None, executables: ExecutablePaths | None=None)
```

A Canvas with linear data mapping, axes, series and legends.

Series/ticks use data coordinates; inherited Canvas primitives use
canvas coordinates. Ranges are explicit: there is no autoscaling,
log-axis transform or plot-area clipping. Use `mapToCanvas`
for data annotations.

**Construction:**

Create a plotting canvas with data-to-canvas coordinate mapping.

`origin` is the canvas position of the bottom-left corner of the plot
area and `margins` the `(right, top)` space left around it. Both
default to `"auto"`: they are sized from the fonts in `style` so
tick labels, axis labels and the title fit. `None` restores the
legacy percentage-based layout (15%/15% left/bottom, 10%/10% right/top).
`extra_margins` = `(left, bottom, right, top)`
is added on top of the automatic margins (e.g. room for rotated tick labels).

Range endpoints must be distinct. Automatic margins are estimated at
construction time, not recomputed after every drawing call. Too-small
automatic layouts warn and fall back to percentage margins.

## Plot.addAxes

```python
Plot.addAxes(color: Color='black', thickness: Number=1, directed: bool=False, *, arrow_size: Number=1, arrow_style: ArrowStyle | None=None) -> None
```

Draw axes along the bottom and left plot boundaries.

Axes do not move to data value zero when the ranges include negatives.
`directed=True` adds arrowheads; no ticks or grid lines are added.

Each axis extends past the plot area by `style.axis_gap` plus the

end before the arrowhead starts. Both axes cross by half a tick notch
at the origin.

## Plot.addPlot

```python
Plot.addPlot(x: Iterable[Number], y: Iterable[Number], color: Color | None=None, thickness: Number=1, interp: bool=False, opacity: Number=1, dashed: bool=False, label: str | None=None, *, step: Literal['post', 'pre', 'mid'] | None=None) -> None
```

Draw paired data with straight segments, steps or an interpolating spline.
