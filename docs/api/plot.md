## PlotStyle

```python
PlotStyle(tick_size: Number=16, label_size: Number=16, title_size: Number=18, *, tick_length: Number=10, tick_pad: Number=0.35, label_pad: Number=0.5, title_pad: Number=0.6, outer_pad: Number=8, line_height: Number=1.2)
```

Font sizes and font-relative spacing shared by a plot's text elements.

Every gap is expressed as a fraction of the font size of the text it
separates, so layouts stay balanced when font sizes change:

* `tick_pad`: gap between the outer end of a tick notch and its label,
  in units of `tick_size`.
* `label_pad`: gap between the outer edge of the tick labels and the
  axis label, in units of `label_size`.
* `title_pad`: gap between the top of the plot area and the title, in
  units of `title_size`.
* `outer_pad`: blank border (user units) kept around the content when
  margins are computed automatically (`origin="auto"` / `margins="auto"`).
* `tick_length`: total length of a tick notch (drawn centred on the axis).

**Construction:**

Set text sizes, notch length and outer padding in user units.

`tick_pad`, `label_pad` and `title_pad` are font-size multipliers;
`line_height` is used in text extent and automatic margin estimates.
See `PlotStyle` for the spacing conventions.

| Parameter | Default | Type / calling convention |
| --- | --- | --- |
| `tick_size` | `16` | `Number` |
| `label_size` | `16` | `Number` |
| `title_size` | `18` | `Number` |
| `tick_length` | `10` | `Number (keyword-only)` |
| `tick_pad` | `0.35` | `Number (keyword-only)` |
| `label_pad` | `0.5` | `Number (keyword-only)` |
| `title_pad` | `0.6` | `Number (keyword-only)` |
| `outer_pad` | `8` | `Number (keyword-only)` |

## Plot

```python
Plot(height: Number, width: Number, origin: Point | Literal['auto'] | None='auto', margins: Point | Literal['auto'] | None='auto', x_range: Point=(0, 1), y_range: Point=(0, 1), *, style: PlotStyle | None=None, extra_margins: Sequence[Number]=(0, 0, 0, 0), executables: ExecutablePaths | None=None)
```

A Canvas with linear data mapping, axes, series and legends.

Series/ticks use data coordinates; inherited Canvas primitives use
canvas coordinates. Ranges are explicit: there is no autoscaling,
log-axis transform or plot-area clipping. Use `mapToCanvas`
for data annotations.

**Construction:**

Create a plotting canvas with data-to-canvas coordinate mapping.

`origin` is the canvas position of the bottom-left corner of the plot
area and `margins` the `(right, top)` space left around it. Both
default to `"auto"`: they are sized from the fonts in `style` so
tick labels, axis labels and the title fit. `None` restores the
legacy percentage-based layout (15%/15% left/bottom, 10%/10% right/top).
`extra_margins` = `(left, bottom, right, top)`
is added on top of the automatic margins (e.g. room for rotated tick labels).

Range endpoints must be distinct. Automatic margins are estimated at
construction time, not recomputed after every drawing call. Too-small
automatic layouts warn and fall back to percentage margins.

| Parameter | Default | Type / calling convention |
| --- | --- | --- |
| `height` | `required` | `Number` |

| `margins` | `'auto'` | `Point \| Literal['auto'] \| None` |

## Plot.putMarker

```python
Plot.putMarker(x: Number, y: Number, marker_type: MarkerType='circle', size: Number=1, color: Color='red', on_canvas: bool=True) -> None
```

Draw a circle, cross or square marker; invalid types raise `ValueError`.

Despite its name, `on_canvas=True` maps `(x, y)` from DATA space.
Pass `False` for raw canvas coordinates. `size` is a scale factor:
circles have radius `5*size`, squares side `9*size`, crosses span
`10*size` user units. Marker sizes do not scale with data ranges.

## Plot.addTicksX

```python
Plot.addTicksX(labels: Iterable[tuple[Number, Any]], color: Color='black', notch_thickness: Number=2, notch_length: Number | None=None, rotation: Number=0, text_anchor: TextAnchor | None=None, text_size: Number | None=None, grid: bool=True, *, pad: Number | None=None) -> None
```

Add x-axis tick labels and optional vertical grid lines.

Labels are placed `pad` below the outer end of the notch (default:

Explicit `pad` uses user units. The minimum-range tick has a label
but no notch/grid line. Draw ticks before `addAxisLabels`.

## Plot.addPlot

```python
Plot.addPlot(x: Iterable[Number], y: Iterable[Number], color: Color='blue', thickness: Number=1, interp: bool=False, opacity: Number=1, dashed: bool=False, label: str | None=None) -> None
```

## Plot.addLegend

```python
Plot.addLegend(anchor: LegendAnchor | None='NE', text_size: Number | None=None, text_color: Color='black', marker_scale: Number=1, box_color: Color='yellow', box_border_color: Color='red', box_opacity: Number=0.5, position: Point | None=None) -> None
```

Draw a legend from previously labeled line, scatter and bar series.

At least one labeled series is required. Entries are sorted by type
(bar, plot, scatter), preserving order within each type. `anchor` is
NE/N/NW/W/E/SW/S/SE inside the plot. `position=(x, y)` overrides it

the data; repeated calls add boxes rather than updating an old one.
